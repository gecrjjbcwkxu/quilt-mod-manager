## Overview

Minecraft Quilt Mod Loader Manager provides a dedicated GUI for managing mods on the Quilt mod loader — the Fabric-compatible fork focused on enhanced mod APIs and stability. It handles mod installation from Modrinth and CurseForge, dependency resolution, profile management, and Quilt Loader version switching.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Minecraft Quilt Mod Loader Manager** delivers the features you need in a clean, intuitive package.

> Official website: [quiltmc.org](https://quiltmc.org)

## Key Features

| Feature | Description |
|---------|-------------|
| **Quilt Profiles** | Manage independent Quilt mod profiles for different playthroughs |
| **Modrinth Integration** | Browse and install Quilt-compatible mods from Modrinth |
| **Dependency Resolver** | Automatic resolution of Quilt API and mod dependencies |
| **Loader Versions** | Switch between Quilt Loader versions per profile |
